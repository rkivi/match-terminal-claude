# Match Terminal plugin marketplace for Claude

This repository is a Claude Code plugin marketplace with one plugin, **match-terminal**. It gives Claude football results, match statistics and pre-match metric breakdowns from [Match Terminal](https://matchterminal.org) through a hosted, read-only MCP server. No API key or account is needed.

```
/plugin marketplace add rkivi/match-terminal-claude
/plugin install match-terminal@match-terminal
```

See [plugins/match-terminal/README.md](plugins/match-terminal/README.md) for tools, example prompts, what data is sent, and the [privacy policy](https://matchterminal.org/privacy).

Not betting advice. Licensed under MIT; the Match Terminal name and logo are excluded.
